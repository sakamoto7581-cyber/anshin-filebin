ファイル暗号化メーカーとは

ファイル暗号化メーカーは、メールに添付できない大きさのファイルや、契約書・個人情報などの機密性の高いファイルを、取引先や家族に安全に渡すための無料のファイル共有ツールです。会員登録は要りません。

暗号化はすべてあなたのブラウザの中で完結します。ファイルはパスワードから作った鍵（AES-GCM 256bit）で暗号化されてからアップロードされるため、サーバーには暗号化されたデータしか残りません。パスワードもサーバーには送られない「ゼロ知識」の仕組みなので、運営者を含め第三者が中身を見ることはできません。

使い方は3ステップ

  1. 送りたいファイルを選ぶ（1ファイル最大50MB）
  2. パスワードを決める（自動生成も可）
  3. 表示された URL とパスワードを、メールとチャットなど別々の手段で相手へ渡す

よくある質問

無料で使えますか？

はい。会員登録も不要で、無料で使えます。

サーバーにファイルの中身を見られることはありますか？

ありません。ファイルは送信者のブラウザの中でパスワードから作った鍵で暗号化され、サーバーには暗号化されたデータしか保存されません。パスワードもサーバーには送られません。

パスワード付きZIP（PPAP）と何が違いますか？

PPAPは「暗号化ZIPとパスワードを同じ経路で送る」運用になりやすく、安全性に課題があります。ファイル暗号化メーカーは暗号化したデータだけをサーバーに預け、URLとパスワードを分けて渡す使い方を前提にしています。保存期間（3日）とダウンロード回数を過ぎると自動で消えます。

送れるファイルの大きさと保存期間は？

1ファイル最大50MBまで送れます。保存期間は3日間で、ダウンロード回数は1〜10回の範囲で送信者が指定します。上限に達するか3日を過ぎると自動で削除されます。

パスワードを忘れたら復旧できますか？

できません。サーバー側にパスワードも平文も無い仕組み（ゼロ知識）のため、復旧手段がありません。もう一度送り直してください。

暗号化方式: PBKDF2-SHA256（600,000回）＋ AES-GCM 256bit ／ Web Crypto API
